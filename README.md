# SCAT Investigation Wizard

A web-based application for systematic cause analysis of workplace accidents, incidents, and near misses. Built using SCAT v8.1 methodology aligned with ILCI standards.

## Overview

SCAT Investigation Wizard is a comprehensive tool designed for Health, Safety, and Environment (HSE) professionals, safety officers, and incident investigation teams. The application provides a structured approach to identifying root causes and generating corrective action recommendations following established safety investigation protocols.

## Features

- Structured 6-step investigation workflow
- Incident type classification with risk assessment
- Direct cause identification (unsafe acts and conditions)
- Root cause analysis (personal and system factors)
- Corrective action planning with implementation tracking
- Automated report generation
- Dark mode support
- Local storage persistence for investigation progress
- Print and PDF export capabilities

## Methodology

The application follows the Systematic Cause Analysis Technique (SCAT) v8.1 framework, which includes:

1. Incident Information Collection
2. Incident Type Identification
3. Direct Cause Analysis (Unsafe Acts and Conditions)
4. Root Cause Identification (Personal and System Factors)
5. Corrective Action Development
6. Final Report Generation

## Usage

1. Open `index.html` in a modern web browser
2. Complete the incident information form
3. Select the incident type from the available options
4. Identify direct causes (unsafe acts and conditions)
5. Analyze root causes (personal and system factors)
6. Select corrective action areas and specific items
7. Generate and export the final investigation report
